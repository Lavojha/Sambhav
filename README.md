# SAMBHAV UPSC

SAMBHAV UPSC is a UPSC preparation platform with:

- PYQ practice
- Prelims tests
- Mains answer writing
- Handwritten answer evaluation
- AI-assisted feedback
- Current Affairs
- Study Material
- Revision
- Performance analytics

## Architecture

- Web: Next.js + TypeScript
- Mobile: Flutter
- Backend: Supabase
- Database: PostgreSQL
- Authentication: Supabase Auth
- Storage: Supabase Storage
- AI: OpenAI
- Validation: Zod

```bash
cd apps/web
npm install
npm run dev
